# Employee Salary & Performance Analysis

## About the Project
This is a beginner-level Data Analytics project that analyzes employee salary, department, and experience data using Python.

## Tools & Libraries
- Python
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

## Analysis Performed
- Basic data exploration
- Salary analysis
- Department-wise employee analysis
- Experience analysis
- Data filtering
- GroupBy and aggregation
- Sorting
- Missing value and duplicate checking
- Calculated columns
- Data visualization

## Visualizations
- Department-wise employee count
- Department-wise salary distribution
- Salary vs Experience
- Salary distribution histogram
- Line chart
- Bar and Pie chart using subplots

## Key Insights
- IT department has the highest number of employees.
- IT department has the highest average salary.
- Arjun has the highest salary.

The complete analysis is available in the Jupyter Notebook:
